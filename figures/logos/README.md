# Official framework logos

These assets are used in the data-source and compatibility rows of Figure 1.

- `pyg.svg`: official PyG wordmark, obtained from
  https://raw.githubusercontent.com/pyg-team/pyg_sphinx_theme/master/pyg_sphinx_theme/static/img/pyg_logo_text.svg
  (also linked from https://github.com/pyg-team/pytorch_geometric).
- `pyg.pdf`: vector PDF converted directly from `pyg.svg` with
  `rsvg-convert --format pdf pyg.svg -o pyg.pdf`.
- `dgl.png`: transparent logo obtained from the official DGL homepage,
  https://www.dgl.ai/assets/images/logo.png (https://www.dgl.ai/).

Retrieved on 2026-11-01. Colors, proportions, and transparency are preserved.
These marks belong to their respective projects.
